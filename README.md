# Backend APIs

Standalone learning repo. Work here on its own — no other repos required.

**Phase (for your own roadmap):** Backend

## Context

APIs are how clients and services talk. REST, GraphQL, and gRPC each have a shape; auth, pagination, and versioning keep them production-ready. Build and document APIs entirely inside this repo.

This repository is the single place for everything related to **Backend APIs**: notes, exercises, and small projects. Clone it, open it, and treat it as a complete unit of study.

## Scope

- REST design: resources, status codes, idempotency
- GraphQL: schema, queries, mutations, N+1 awareness
- gRPC and protobuf intuition
- Auth: JWT, OAuth/OIDC at a practical level
- Pagination, filtering, versioning
- Error contracts and API documentation habits

## Outcomes

When you are done with this repo, you should be able to:

- Design and implement a small API with clear contracts
- Add auth and pagination correctly
- Compare REST vs GraphQL vs gRPC for a given client need

## How to work in this repo

1. Read / write concept notes under `notes/`.
